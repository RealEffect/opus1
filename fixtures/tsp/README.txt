Excerpts of the TSP speech database (McGill University, Telecommunications
and Signal Processing Laboratory), 48 kHz version, by Peter Kabal.
Licence: simplified BSD, in Licence.txt (copied unchanged from the archive).

Each file holds the first 2.5 s (120000 samples) of one sentence, as 16-bit
mono PCM at 48 kHz. Nothing else was changed.

  FA01_05.wav   from 48k/FA/FA01_05.wav (female talker FA)
  MD19_04.wav   from 48k/MD/MD19_04.wav (male talker MD)
  FJ55_02.wav   from 48k/FJ/FJ55_02.wav (female talker FJ)
  MH43_04.wav   from 48k/MH/MH43_04.wav (male talker MH)

The built-in "quick" and "selftest" sets of examples/eval use them, so these
sets run without the corpus.
